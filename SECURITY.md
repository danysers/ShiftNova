# Política de seguridad

ShiftNova procesa perfiles y colores de forma local. El único acceso de red propio de la extensión consulta los manifiestos de versión publicados en `danysers.github.io/ShiftNova`.

Para informar una vulnerabilidad, utiliza de manera privada **Security > Report a vulnerability** en el repositorio [danysers/ShiftNova](https://github.com/danysers/ShiftNova/security/advisories/new). No publiques credenciales, datos de SIARH ni detalles explotables en un issue abierto.

Se mantiene la versión `1.x` con correcciones de seguridad. La rama `main` puede contener cambios todavía no publicados.
